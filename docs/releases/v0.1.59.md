# v0.1.59 — 高清修复：4M / 8M / 20M @ 60fps

## 主要修复

**根因：libnx 默认 UDP 接收缓冲只有 42 KB（`0xA500`）。** 视频按帧突发到达时缓冲溢出，
固定丢包 4~8%，进而引发服务器降码率、客户端整帧 IDR 风暴、参考链断裂 —— 表现为周期性竖线、
局部模糊、帧率 60→33。提升到 256 KB 后丢包归零，高码率档全部可用。

- UDP 接收缓冲 42 KB → 256 KB（`socketInitialize` 自定义 `udp_rx_buf_size`，失败回退默认）
- TWCC 反馈修正：`reference time` 改为规范 64 ms（原 6.25 ms，差 10 倍导致码率崩到几百 kbps）；
  缺口按真实收发状态编码；批内到达时间锚定平滑，消除突发锯齿
- 关键帧请求修正：libdatachannel 的 PLI packet sender SSRC 填错，服务器无视；改用本端 SSRC
  发送 PLI + FIR，实测缺口→IDR 中位数 1 ms
- 丢包不再上报给服务器速率控制器（RTCP RR 同步清零），避免"丢包→降码率→丢更多帧"
- NAL 扫描改为遍历整帧（SPS + PPS + IDR），关键帧识别与冻结逻辑恢复
- 缺口不再 flush 解码器，冻结在最后一张好画面并立即请求 IDR
- 渲染侧 2 帧节奏缓冲 + 共享帧指针（去掉每帧 3.7 MB 拷贝）
- 诊断日志改后台异步批量写，修复 128 KB 滚动卡死
- 本地绘制鼠标箭头

## 安装说明（重要）

本发行包的 **NRO 不包含签名密钥**（密钥从官方 APK 提取，不随任何发行物分发）。
首次使用前：

1. `UURemote-ns.nro` → `/switch/UURemote-ns/UURemote-ns.nro`
2. 用你自己的 UU TV 3.5.0 APK 提取密钥：
   `python extract_key.py 你的APK --output signing.key`
3. `signing.key`（24 字节）→ `/switch/UURemote-ns/signing.key`

详见包内 `README-安装说明.txt`。
