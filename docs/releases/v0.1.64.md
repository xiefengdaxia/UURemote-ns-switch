# v0.1.64 — 触屏模式 + 连接超时修复

## 新增：触屏模式

串流中按 **R3（右摇杆按下）** 切换 鼠标模式 ↔ 触屏模式，HUD 显示 `· 触屏`。

| 手势 | 行为 |
| --- | --- |
| 单指点按 | 在触点位置左键单击 |
| 单指拖动 | 按下并拖动（拖选、画线、拖文件） |
| 长按 0.65 秒 | 右键（弹出上下文菜单），判断标准是按住期间位移不超过 10px |
| 双指上下/左右滑动 | 滚动（发送 `two_fingers_scroll`） |

触屏模式不显示鼠标箭头，改为半透明触控圆圈指示当前位置；手指移出画面黑边会自动释放按键。

## 修复：建立音视频通道超时

实测 STUN/TURN 候选收集在部分网络下需要 **40 秒**，而原实现的连接超时是 45 秒，
候选刚收集完 7 秒就判定超时，导致"建立音视频通道失败"。

- 总超时 45 秒 → **75 秒**
- 候选收集完成（gathering complete）时再顺延 30 秒，保证 ICE/DTLS 有完整时间窗口

## 其它

- 触屏输入与鼠标输入共用同一条控制通道；连发移动事件在 SCTP 拥塞时会自动丢弃，不会堆积
- 诊断新增 `scroll-<dx>-<dy>`（双指滚动量）

## 安装说明（重要）

本发行包的 **NRO 不包含签名密钥**（密钥从官方 APK 提取，不随任何发行物分发）。首次使用前：

1. `UURemote-ns.nro` → `/switch/UURemote-ns/UURemote-ns.nro`
2. 用你自己的 UU TV 3.5.0 APK 提取密钥：
   `python extract_key.py 你的APK --output signing.key`
3. `signing.key`（24 字节）→ `/switch/UURemote-ns/signing.key`

详见包内 `README-安装说明.txt`。
